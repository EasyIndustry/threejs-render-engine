# Seguridad

Un problema de seguridad **no va en un issue público**. Reportalo en privado desde la pestaña
*Security* del repo ([reportar una vulnerabilidad](https://github.com/EasyIndustry/threejs-render-engine/security/advisories/new)),
con qué versión, cómo reproducirlo y qué permite.

Se responde, se arregla en una versión nueva y se publica el aviso cuando la versión arreglada
está disponible, con crédito para quien lo reportó si lo quiere.

Se arregla sobre la última versión publicada. Una app que vendoriza el módulo actualiza su copia
(ver [`POLITICA.md`](POLITICA.md), *Vendorizar*).
